# Firefighter Robot: "Remarkable Doorstop"
An autonomous omni-directional robot engineered to solve mazes, avoid obstacles, and extinguish fires.

- **Language & Tools:** Great Cow Basic (GCBasic)
- **Key Features:** 
  - **Wall Detection** - IR sensors placed on front and left side of robot for live wall tracking.
  - **Flame Detection** - Phototransistor tuned to detect light in entrance of room to reduce maze solve times.
  - **Motor Control** - Motor driver control to direct motors for omnidirectional movement.
- **Takeaway:** Designed and debugged navigation and detection logic for PIC microcontrollers.

## OBJECTIVES:
- Robot must not have any human input during the run
- Robot must start at designated spot during the start of the solve
- Robot must fit within a 31 by 31 by 27 cm box
- Robot must be within 30 cm in order to extinguish candle
- Robot must not touch the candle during extinguishing
- In order to complete a maze robot must clear all other rooms before extinguishing the candle (Room 4)
- Within the room 4 solve the robot must use the same code to clear all rooms
- Robot cannot extinugish the candle in any ways that could be damaging or harmful
